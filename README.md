# lab4_veb
# Лабораторна робота №4
 «Вебформи та елементи керування»

**Студентка:** Житник Ксенія (група ІН-41.1)  
**Предметна область:** Психологічна студія та простір тілесних практик «USVIDOM» (м. Буча).

 Опис виконаної роботи:
У межах лабораторної роботи розширено статичний вебпроєкт інтерфейсом адміністратора та формами зворотного зв'язку засобами HTML5 (без використання стилів і JavaScript):
1. **`admin.html`** — сторінка імітації адміністрування з таблицею поточних елементів та формою додавання нового спеціаліста.
2. **`admin-edit.html`** — сторінка редагування існуючого елемента з попередньо заповненими полями та прихованим `id`.
3. **`details.html`** — сторінка детального опису послуги з інтегрованою формою відгуку відвідувача.

 Використані технології:
* HTML5 (семантичні теги, `fieldset`, `legend`, `label`, `table`, `scope`)
* Доступність (атрибути `autocomplete`, `aria-describedby`)
* Вбудована валідація (`required`, `min`, `max`, `step`, `pattern`, `minlength`, `maxlength`)
